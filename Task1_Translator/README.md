# AI Language Translator

An advanced AI-powered Language Translator developed using Python and Tkinter. The application enables users to translate text between multiple languages, automatically detect the source language, convert speech to text, and listen to translated content through text-to-speech functionality.

## Features

Translate text into multiple languages

 Auto Language Detection

Speech-to-Text (Voice Input)

Text-to-Speech (Audio Output)

Dark Mode / Light Mode Toggle

Translation History Tracking

Copy Translation to Clipboard

Save Translation as Text File

Searchable Language Selection

Modern and User-Friendly GUI

## How to Use

1. Enter text in the input area.
2. Select the target language.
3. Click **Translate**.
4. View translated text in the output area.
5. Use **Voice Input** to convert speech into text.
6. Use **Speak** to listen to translated text.
7. Save or copy translations as needed.
8. Switch between Dark and Light modes.
